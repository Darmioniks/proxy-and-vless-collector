# Proxy Manager

Windows-приложение для поиска рабочих VLESS-ключей и MTProto-прокси Telegram. Проект разработан Darmioniks.

Основной интерфейс открывается в отдельном desktop-окне через pywebview. FastAPI работает внутри приложения на случайном локальном порту `127.0.0.1` и не требует отдельного браузера или Streamlit.

## Возможности

### VLESS

- загрузка ключей из встроенного списка публичных источников;
- проверка собственного `.txt` или вставленного списка `vless://`;
- отдельный каскад для каждого ключа: TCP → TLS → Xray;
- немедленное отображение ключа после прохождения его каскада;
- остановка новых проверок после получения указанного количества результатов;
- опциональный замер скорости найденных ключей;
- скачивание результатов в TXT;
- создание временной локальной ссылки-подписки;
- автоматическое сохранение успешных результатов в SQLite.

### Фильтры стран

Geo-IP выполняется до TCP, TLS и Xray, поэтому заведомо ненужные страны не расходуют время основного каскада.

- **Разрешённые страны** — если список заполнен, остаются только выбранные страны. IP с неопределённой страной отсеиваются.
- **Чёрный список стран** — выбранные страны исключаются. IP с неопределённой страной остаются в проверке.
- Одна страна не может одновременно находиться в обоих списках: интерфейс автоматически переносит её в последний выбранный список, а API дополнительно проверяет конфликт.
- Результаты Geo-IP сохраняются в SQLite на 30 дней.

Определение стран использует batch API `ip-api.com`. Первый запуск на большой базе может занять несколько минут из-за сетевых ограничений сервиса.

### Лимит проверок

Поле **«Максимум проверок»** ограничивает число VLESS-кандидатов, которые попадут в каскад после обычных и географических фильтров.

Флажок **«Без лимита»** отключает это ограничение. В таком режиме приложение может пройти всю доступную после фильтрации базу, но всё равно завершит запуск раньше, если уже найдено требуемое количество рабочих ключей.

### Telegram-прокси

Вкладка **«Telegram-прокси»**:

1. Загружает MTProto-ссылки из четырёх публичных источников.
2. Нормализует ссылки `tg://proxy` и `https://t.me/proxy`.
3. Удаляет дубликаты по `server:port`.
4. Перемешивает базу и проверяет заданное количество прокси по TCP.
5. Сортирует доступные прокси по пингу.
6. Открывает выбранный прокси через зарегистрированный протокол Telegram.

TCP-проверка подтверждает доступность адреса и порта, но не гарантирует, что Telegram успешно авторизуется через прокси после подключения.

### Happ

Кнопка **«Добавить в Happ»** открывает установленный Happ со стандартной подпиской:

```text
https://raw.githubusercontent.com/Darmioniks/mtproto-proxy-tg/main/vless_filtered.txt
```

Используется deep link вида `happ://add/https://...`. Если Happ не установлен, обычная ссылка копируется в буфер обмена для ручного импорта.

## Проверка VLESS

Для каждого кандидата последовательно выполняются:

1. **TCP** — подключение к `host:port`. Результат кэшируется для ключей с одинаковым endpoint.
2. **TLS** — handshake с SNI/Host для `security=tls` и `security=reality`. Результат также кэшируется.
3. **Xray** — отдельный локальный SOCKS-процесс, два успешных ответа независимых URL и загрузка минимум 256 КБ.

На Windows дочерние процессы Xray запускаются с `CREATE_NO_WINDOW`, поэтому во время параллельной проверки консольные окна не появляются.

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python desktop.py
```

Для строгой проверки положите `xray.exe` в корень проекта или добавьте Xray в `PATH`. Без Xray доступны TCP и TLS; соответствующие элементы интерфейса будут отключены.

## Сборка Windows EXE

```powershell
.\build_desktop.ps1
```

Результат:

```text
dist\ProxyManager.exe
```

В EXE включаются Python runtime, HTML/CSS/JavaScript, FastAPI, pywebview и локальный `xray.exe`.

## Веб-режим для разработки

```powershell
uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Desktop-интеграции Happ и Telegram в браузерном режиме недоступны, но ссылки передаются установленным обработчикам протоколов браузера.

## Данные приложения

Desktop-версия хранит данные здесь:

```text
%LOCALAPPDATA%\Darmioniks\ProxyManager\proxy_manager.db
```

SQLite содержит:

- рабочие VLESS-ключи и их метрики;
- Geo-IP-кэш;
- историю количества ключей в источниках;
- локальные ссылки-подписки.

MTProto-прокси между запусками не сохраняются: вкладка получает актуальный список при каждом нажатии **«Загрузить и проверить»**.

## Ограничения

- Все VLESS и MTProto-источники сторонние и могут быть временно недоступны.
- Успешный TCP или TLS handshake не равен полноценной проверке трафика; для VLESS используйте Xray-этап.
- Локальная ссылка-подписка работает только пока запущено приложение.
- Geo-IP зависит от доступности `ip-api.com` и точности его базы.
- Desktop deep links требуют установленных Happ и Telegram с зарегистрированными Windows-протоколами.

Используйте сторонние ключи и прокси на свой риск и с учётом законодательства вашей юрисдикции.
